# Sprint 1 MVP — TocaYJuga (Marketplace de Reservas de Canchas) — Plan de Implementación

> Plan pensado para ejecución humana (equipo de 3, sprint de 2 semanas), no para subagentes automatizados. No usar `superpowers:subagent-driven-development` — seguir fase por fase en sesiones de código reales, un PR por task.

**Goal:** Sprint 1 completo y funcional en demo: registro/login con roles, ABM de complejos y canchas, definición de horarios, y que un jugador pueda consultar disponibilidad y reservar una cancha.

**Architecture:** Next.js 15 monolito (App Router). Route Handlers / Server Actions como backend. Prisma sobre PostgreSQL. Auth.js para sesión y roles. Sin mapa/geocoding todavía. Imágenes en Vercel Blob (no filesystem).

**Tech Stack:** Next.js 15, TypeScript strict, Tailwind, shadcn/ui, React Hook Form + Zod, Prisma + PostgreSQL, Auth.js (Credentials + argon2), react-big-calendar, Docker (Postgres local), Vercel (deploy + Blob).

**Spec:** DER provisto por el cliente (adjunto en la conversación) + brief de requisitos Sprint 1 (registro/ABM roles, ABM complejos, ABM canchas, horarios, consulta+reserva). No hay archivo de spec separado — los requisitos y decisiones de stack quedan documentados acá.

## Global Constraints

- TypeScript `strict: true` desde el día 1 — no "modo relajado".
- Nada de subida de archivos a filesystem local — todo upload de imagen va a Vercel Blob.
- No integrar mapas/geocoding en este sprint — no está en el alcance de Sprint 1.
- Todo endpoint/Server Action valida input con Zod antes de tocar DB.
- Passwords: argon2, nunca texto plano.
- `.env` en `.gitignore` desde el primer commit.
- Un dueño no puede editar/ver canchas o complejos que no son suyos (chequeo de ownership server-side, no solo UI).
- Reservas: constraint a nivel DB que impida dos reservas pisadas en la misma cancha/fecha/horario (no confiar solo en chequeo de aplicación).

## Decisión de modelado: simplificación del DER

El DER muestra `Jugador` y `Dueño` como sub-tipos de `Usuario` sin atributos propios. Implementación: **una sola tabla `Usuario`** con campo `rol` (`JUGADOR` | `DUENIO`). `Reserva.jugadorId` y `Complejo.duenioId` apuntan directo a `Usuario.id`. Evita join extra y tablas vacías — mismo modelo conceptual, menos piezas.

`Pago` (del DER) queda **fuera de Sprint 1** — ningún requisito de este sprint pide procesar/mostrar pagos todavía. Se agrega en el sprint que lo pida.

`Horarios disponibles`: el DER no tiene una entidad para esto. En vez de crear una tabla de slots pre-generados, `Cancha` guarda `horaApertura`, `horaCierre`, `duracionTurnoMin`. La disponibilidad para una fecha se **calcula on-the-fly**: turnos posibles (apertura→cierre en bloques de duración) menos los que ya tienen `Reserva`. Menos estado que mantener sincronizado, un solo lugar de verdad (la tabla `Reserva`).

// auth.ts
import NextAuth from 'next-auth'
import Credentials from 'next-auth/providers/credentials'
import argon2 from 'argon2'
import { db } from '@/lib/db'

export const { handlers, auth, signIn, signOut } = NextAuth({
  providers: [
    Credentials({
      credentials: { email: {}, password: {} },
      authorize: async (credentials) => {
        const usuario = await db.usuario.findUnique({
          where: { email: credentials.email as string },
        })
        if (!usuario) return null
        const valido = await argon2.verify(usuario.passwordHash, credentials.password as string)
        if (!valido) return null
        return { id: usuario.id, name: usuario.nombre, email: usuario.email, rol: usuario.rol }
      },
    }),
  ],
  callbacks: {
    jwt: ({ token, user }) => {
      if (user) token.rol = user.rol
      return token
    },
    session: ({ session, token }) => {
      session.user.rol = token.rol as 'JUGADOR' | 'DUENIO'
      return session
    },
  },
  pages: { signIn: '/login' },
})

// middleware.ts
import { auth } from '@/auth'
import { NextResponse } from 'next/server'

export default auth((req) => {
  const rol = req.auth?.user?.rol
  const path = req.nextUrl.pathname

  if (path.startsWith('/dueno') && rol !== 'DUENIO') {
    return NextResponse.redirect(new URL('/', req.url))
  }
  if (path.startsWith('/jugador') && rol !== 'JUGADOR') {
    return NextResponse.redirect(new URL('/', req.url))
  }
  if ((path.startsWith('/dueno') || path.startsWith('/jugador')) && !req.auth) {
    return NextResponse.redirect(new URL('/login', req.url))
  }
})

export const config = {
  matcher: ['/dueno/:path*', '/jugador/:path*'],
}

## Fase 4 — Disponibilidad y reserva (rol Jugador)

### Task 4.1: Calcular disponibilidad de una cancha para una fecha

**Files:**

- Create: `lib/services/disponibilidad.ts`

**Interfaces:**

- Consume: `Cancha` (horaApertura/horaCierre/duracionTurnoMin), `db.reserva.findMany`
- Produce: `obtenerSlotsDisponibles(canchaId: string, fecha: Date): Promise<{ horaInicio: string; horaFin: string; disponible: boolean }[]>`

```typescript
// lib/services/disponibilidad.ts
import { db } from '@/lib/db'

function generarSlots(horaApertura: string, horaCierre: string, duracionMin: number) {
  const slots: { horaInicio: string; horaFin: string }[] = []
  let [h, m] = horaApertura.split(':').map(Number)
  const [hFin, mFin] = horaCierre.split(':').map(Number)

  while (h < hFin || (h === hFin && m < mFin)) {
    const inicio = `${String(h).padStart(2, '0')}:${String(m).padStart(2, '0')}`
    m += duracionMin
    h += Math.floor(m / 60)
    m = m % 60
    const fin = `${String(h).padStart(2, '0')}:${String(m).padStart(2, '0')}`
    slots.push({ horaInicio: inicio, horaFin: fin })
  }
  return slots
}

export async function obtenerSlotsDisponibles(canchaId: string, fecha: Date) {
  const cancha = await db.cancha.findUniqueOrThrow({ where: { id: canchaId } })
  const todosLosSlots = generarSlots(
    cancha.horaApertura,
    cancha.horaCierre,
    cancha.duracionTurnoMin,
  )

  const reservas = await db.reserva.findMany({
    where: { canchaId, fecha, estado: { not: 'CANCELADA' } },
  })
  const ocupados = new Set(reservas.map((r) => r.horaInicio))

  return todosLosSlots.map((slot) => ({ ...slot, disponible: !ocupados.has(slot.horaInicio) }))
}
```

  const session = await auth()
  if (!session || session.user.rol !== 'JUGADOR') return { error: 'No autorizado' }

  try {
    await db.reserva.create({
      data: {
        canchaId,
        jugadorId: session.user.id,
        fecha: new Date(fecha),
        horaInicio,
        horaFin,
        estado: 'CONFIRMADA',
      },
    })
    return { ok: true }
  } catch (e) {
    if (e instanceof Prisma.PrismaClientKnownRequestError && e.code === 'P2002') {
      return { error: 'Ese horario ya fue reservado' }
    }
    throw e
  }
}
